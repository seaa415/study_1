# 씬룸 — GitHub + Vercel 배포용

작가교육원 스터디 팀의 집필·합평 작업실입니다. 기존 화면과 기능을 표준 Next.js + Supabase로 이전했습니다. 기존 Sites 프로젝트와 별도 디렉터리에 있으며 이 프로젝트만 GitHub에 올립니다.

- 멤버별 작품·진행률, Google 문서 링크, 초고/수정고 버전
- 합평 기록·참여자·체크리스트, 수정 가능한 스터디 규칙
- 이론서·작품 분석 자료와 댓글, 최대 10MB 파일 첨부
- 공개 목표·출석 인증, 단체 목표·D-Day 캘린더
- 이메일 인증 코드 로그인, 계정별 프로필과 개인 룸
- 작품·목표·자료의 ‘나만 보기 / 스터디 공유’

## 실행

Node.js 22 이상을 설치하고 다음 명령을 실행합니다.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

`.env.local`의 두 값은 Supabase 프로젝트에서 복사합니다. 설치 없이 소스만 업로드한 뒤 Vercel 빌드를 실행해도 됩니다. 연결 값이 없으면 화면을 빌드할 수는 있지만 로그인·저장은 작동하지 않습니다.

```sh
npm run typecheck
npm test
npm run build
```

## 온라인 게시

`DEPLOY.md`를 순서대로 따라 주세요. 먼저 Supabase의 SQL과 메일 발송을 설정한 후, 이 폴더를 GitHub 저장소의 루트에 올리고 Vercel에 연결합니다. 빌드·타입 검사·Postgres 기반 권한 검사를 통과했습니다. 실제 Supabase 프로젝트 연결, 이메일 발송 및 실제 계정 로그인 검증은 아직 수행하지 않았습니다.

## 데이터와 권한

공유한 자료는 링크 방문자가 볼 수 있습니다. 로그인·프로필이 필요한 쓰기 작업은 본인 계정으로 기록되며, 개인 작품과 자료는 작성자만 수정할 수 있습니다. 단체 목표와 규칙은 로그인한 멤버가 공동 편집합니다. 동일 닉네임을 선택해도 계정은 분리됩니다.

데이터 권한은 Supabase RLS와 서버에서 확인합니다. 저장소는 비공개 버킷이며 공유된 자료에 첨부한 파일만 다른 사람이 다운로드할 수 있습니다. 다운로드 URL은 60초 동안 유효하므로 이미 발급된 다운로드 URL은 공유 해제 후에도 최대 60초 동안 유효할 수 있습니다. 외부 Google 문서의 접근 권한은 해당 문서에서 설정해야 합니다.

가입은 링크 방문자에게 열려 있습니다. 스터디 전용 초대 제한은 포함하지 않습니다. 공모전 날짜는 직접 입력하며 알림은 사이트 내에서 표시합니다.

## 기존 데이터

기존 프로젝트 `work/study`와 로컬 저장소는 그대로 보존했습니다. 이전 로그인 계정과 Supabase 계정의 ID가 다르므로 기존 데이터는 자동 복사하지 않습니다. 소스 ZIP에는 멤버의 실제 데이터·파일·비밀번호·API 비밀키가 포함되지 않습니다.
